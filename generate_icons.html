🎨 SLR Search Scanner – Icon Generator

Hướng dẫn:
1. Mở file này trong Google Chrome
2. Bấm "⬇ Download All Icons"
3. Lưu 3 file PNG vào thư mục slr-search-scanner/icons/
4. Đặt tên đúng: icon16.png, icon48.png, icon128.png
✅ Tất cả icon đã được tải xuống! Chuyển vào thư mục icons/ rồi cài extension.
